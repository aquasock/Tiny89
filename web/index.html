Tiny89 image builder

Boots your TI-89 Titanium operating system in an emulated calculator, installs the files you choose with the calculator's own software, and writes out the flash and RAM images the Tang loads.

1 · Operating system

The upgrade file TI distributes (.89u). It stays in this tab; nothing is uploaded anywhere.

2 · Your files

Programs, variables and data to install (.89k .89y .89z .89p and the rest). Flash Apps are recognised and reported, but their exchange is not implemented yet.
